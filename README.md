## 1. Штолле (сеть пироговых)

- **Сайт:** https://stolle.by
- **Специализация:** пироги на заказ, кафе-пироговые, доставка/самовывоз
- **Архитектура/логика:** каталог продукции, корзина, доставка по городу
- **Технологический стек:** Next.js (React-фреймворк — виден по пути `_next/static/chunks/...`
  в запросах), styled-components (CSS-in-JS — автогенерированные классы вида `sc-xxxxxxx-0`),
  сборка через Webpack (`webpackChunk` в исходном коде JS). Заголовки `Server` и `X-Powered-By`
  в ответе сервера скрыты/отсутствуют — стек определён по косвенным признакам во фронтенд-коде.
- **Семантические элементы HTML5:**
  header — 1, nav — 2, main — 2, section — 6, article — 0, footer — 1
- **Div и семантические классы:** явных смысловых классов (`.card-product` и т.п.) нет —
  все классы автоматически сгенерированы styled-components, например `sc-1db3fbc3-0`,
  `sc-a18cc9f5-0`, `sc-a121a94a-0`, `sc-1fe9b14c-0` (хэш-подобные имена без смысловой нагрузки).
- **Адаптивность (media-запросы):** сайт адаптивен на обоих брейкпоинтах (375px и 768px) —
  принципиальных отличий в структуре нет, интерфейс подстраивается плавно (гибкая/резиновая
  вёрстка), без смены сетки колонок или скрытия элементов.
- **Lighthouse:** Performance — 43, Accessibility — 88, Best Practices — 96, SEO — 92
  Условия проверки: мобильный интернет / дом / 11:50, 23.09.2026
- **LocalStorage / Cookies:** `cookiePolicy: true` — флаг, что пользователь принял cookie-баннер
  (согласие сохраняется, чтобы баннер не показывался повторно). `cookiesSettings:
  {"adStorage":true,"analyticsStorage":true}` — настройки согласия на хранение данных: отдельно
  для рекламы (adStorage) и отдельно для аналитики (analyticsStorage) — это формат Google
  Consent Mode, используемый для управления Google Analytics/Google Ads с учётом согласия
  пользователя.
- **Маркетинг и аналитика:** на сайте обнаружен `partytown-sandbox-sw.html` — библиотека
  Partytown, которая используется специально для фоновой загрузки сторонних скриптов
  (аналитика, пиксели). Живая проверка через Network: по фильтрам `analytics`, `metrika`,
  `pixel`, `tagmanager`, `hotjar` запросов не обнаружено — конкретный сервис аналитики,
  который Partytown должен грузить, определить не удалось (либо он не сработал в момент
  проверки, либо загружается только после действия пользователя).

## 2. Гроднохлебпром

- **Сайт:** https://www.minskhleb.by
- **Специализация:** крупнейшее хлебопекарное предприятие Беларуси (6 хлебозаводов),
  интернет-магазин с каталогом 700+ хлебобулочных и кондитерских изделий
- **Архитектура/логика:** большой каталог с подробным описанием каждого товара
  (вес, штрихкод, состав, энергетическая ценность), поиск по ассортименту
- **Технологический стек:** CMS — 1С-Битрикс (используется и для e-commerce-модуля).
  Backend: PHP 7.4.33, веб-сервер/обратный прокси — Nginx. Frontend: jQuery 1.12.4 + jQuery UI
  1.12.1, Slick (слайдер), FancyBox 2.1.5 (модальные окна/галереи), lit-html/lit-element
  3.3.3/4.2.2 (веб-компоненты — вероятно, для одного отдельного виджета типа intro-offer
  попапа), core-js (полифиллы для старых браузеров). Шрифты — Google Font API, иконки —
  Font Awesome 4.5.0. Карта — Google Maps. CDN — jQuery CDN. Служба доставки — Ecovium.
- **Семантические элементы HTML5:** header — 0, nav — 0, main — 0, section — 1, article — 0,
  footer — 1. Семантика HTML5 почти не используется: шапка, меню и основной контент сверстаны
  через `<div>` (характерные для 1С-Битрикс классы с префиксами bx-*, header_wrap,
  wrapper_inner), и лишь единичные `<section>` и `<footer>` вставлены точечно.
- **Div и семантические классы:** используются частично осмысленные классы, но не в едином
  стиле (без БЭМ) — примеры: `.header_wrap`, `.wrapper_inner.not_main_wrapper`, `.main_title`,
  `.top-h-row`, `.footer_copyright`. Плюс служебные Битрикс-классы на `<html>`/`<body>`:
  `bx-core`, `bx-android`, `bx-touch`, `bx-retina`, `bx-chrome`.
- **Адаптивность (media-запросы):** сайт адаптивен на обоих брейкпоинтах (375px и 768px) —
  принципиальных отличий в структуре нет, интерфейс подстраивается плавно (гибкая/резиновая
  вёрстка), без смены сетки колонок или скрытия элементов.
- **Lighthouse:** Performance — 59, Accessibility — 83, Best Practices — 54, SEO — 92
  (проверено на странице /clients/requisites/, а не на главной — можно перепроверить
  на главной странице для более показательного результата)
  Условия проверки: мобильный интернет / дом / 11:50, 23.09.2026
- **LocalStorage / Cookies:** Local Storage полностью занят служебными данными Яндекс.Метрики
  (префикс `_ym_*`): `_ym_uid` (уникальный ID посетителя), `_ym_lastHit`/`_ym_reqNum` (счётчики
  визитов), `_ym_synced`, `_ym_fip` (fingerprint браузера для идентификации), `_ym_zzlc` и др. —
  всего 11 ключей, все относятся к отслеживанию поведения пользователя, никаких пользовательских
  данных (корзина, настройки интерфейса) в localStorage не хранится.
- **Маркетинг и аналитика:** в `<head>` напрямую подключены: Google Analytics
  (ssl.google-analytics.com/ga.js), Яндекс.Метрика (mc.yandex.ru/metrika/watch.js и tag.js),
  Google Tag Manager (googletagmanager.com/gtag/js и gtm.js, id=GTM-NW672Z7X). Через Network
  подтверждена отправка событий в GA4 (`collect?v=2&tid=G-BF5GF21M...`). Также есть
  верификационные метатеги Яндекс.Вебмастера и Google Search Console.

## 3. 21vek.by — раздел выпечки/кондитерки

- **Сайт:** https://21vek.by
- **Специализация:** крупный онлайн-гипермаркет, выпечка — один из разделов широкого каталога
- **Архитектура/логика:** полноценный e-commerce: фильтры, корзина, доставка по всей Беларуси,
  самовывоз, бонусная система, кредитная программа
- **Технологический стек:** фронтенд — Next.js (React-фреймворк), JavaScript/TypeScript; на
  внутренних страницах подключается jQuery. В путях статики видно
  `cdn21vek.by/desktop/_next/static/...` — прямое подтверждение сборки Next.js. Подтверждено
  живым Wappalyzer: React, Next.js, Envoy (обратный прокси). Из структурированных данных
  используются Open Graph, Microdata и JSON-LD, что помогает с SEO и превью в соцсетях.
- **Семантические элементы HTML5:** header — 3, nav — 0, main — 1, section — 3, article — 0,
  footer — 1 (цифры перепроверены живьём с точным поиском по `<тег`).
- **Div и семантические классы:** используются CSS Modules — имена классов осмысленные и
  описывают назначение блока (HeaderQrBanner_container, HeaderQrBanner_banner,
  HeaderQrBanner_title, Text-module_bold), но к каждому автоматически добавлен уникальный
  хэш-суффикс сборщика (например `__MBQiR`, `__irj3W`). Это среднее между полностью
  автогенерированными классами (как у Штолле на styled-components) и классическим ручным
  БЭМ — читаемость для разработчика сохранена, но итоговый HTML не содержит "чистых"
  человекочитаемых имён.
- **Адаптивность (media-запросы):** сайт использует отдельный мобильный поддомен m.21vek.by
  (редирект 301 с www.21vek.by), а не единую адаптивную вёрстку на media-запросах. Десктопная
  и мобильная версии различаются вёрсткой на уровне отдельных сборок Next.js, а не CSS-
  брейкпоинтов одного и того же HTML.
- **Lighthouse:** Performance — 55, Accessibility — 75, Best Practices — 100, SEO — 100
  Условия проверки: мобильный интернет / дом / 11:50, 23.09.2026
- **LocalStorage / Cookies:** LocalStorage на m.21vek.by исключительно насыщен маркетинговыми
  и аналитическими сервисами (существенно больше, чем у Штолле и Гроднохлебпром):
  - Яндекс.Метрика (`_ym_*`)
  - Google Ads / Click ID (`_gcl_ls`)
  - Segment.com — платформа маршрутизации событий в аналитику (`ajs_anonymous_id`, `ajs_user_id`)
  - PopMechanic — сервис управления попапами/промо-предложениями (`popmechanic.*`, много ключей)
  - Mindbox — CDP/CRM для персонализации и бонусной программы (`mindboxDeviceUUID`,
    `persist:profile`)
  - Топ.Mail.ru/Rambler counter (`tmr_*`)
  - собственный `userUuid` для идентификации пользователя

  Это говорит о зрелой, многоуровневой маркетинговой инфраструктуре — в отличие от Штолле
  (только базовая аналитика через Partytown) и Гроднохлебпром (GA+Метрика+GTM, но без CDP
  и персонализации).
- **Маркетинг и аналитика:** - `analytics` — не обнаружено напрямую по этому слову `metrika` — подтверждена Яндекс.Метрика: tag.js, tag_ec.js (e-commerce-модуль), dvert.gif (конверсионный пиксель ретаргетинга) `pixel` — подтверждён Segment.com: pixel.js, identify_*.js, серия ping-запросов "pixel" — совпадает с ajs_anonymous_id/ajs_user_id, найденными в localStorage `tagmanager` — подтверждён Google Tag Manager (GTM-5MH...) и через него GA4 (G-KBL22GMK8...), с отправкой событий (collect rcb=7&frm=0...) - `hotjar` — не обнаружено

## 4. Чайкоффский — местная пекарня

- **Сайт:** https://chaikoffskiy.by/
- **Специализация:** пекарня «Душевная выпечка» (пироги и торты под заказ) + чайный дом
  «ЧайКоффский» (розница чая, кофе, аксессуаров для чаепития). Сеть из 7 точек в Гродно,
  доставка по Гродно и по Беларуси. Юрлицо — ООО «Чайный дом ЧайКоффский».
- **Архитектура/логика:** два параллельных каталога — «Каталог выпечки» и «Каталог чая и кофе»,
  корзина, отдельная страница «Доставка и оплата», личный кабинет с «Историей заказов»,
  «Дисконтная карта» (бонусная система), плюс собственное мобильное приложение (ссылка вида
  `onelink.to/...` — deep-link сервис уровня AppsFlyer/Branch).
- **Технологический стек:** CMS — WordPress 7.1.2, база данных — MySQL; электронная коммерция —
  WooCommerce 11.1.2; конструктор страниц — Divi 4.27.9 (поверх темы Saphali Lite); backend —
  PHP 7.4.33, веб-сервер — LiteSpeed, протокол — HTTP/3. Frontend: jQuery 3.7.1 + jQuery Migrate
  3.4.1, Underscore.js 1.13.8, core-js 3.39.0, Select2, PhotoSwipe, prettyPhoto (легаси-плагин),
  MediaElement.js 4.2.17 (фоновое видео на главной). SEO — Yoast SEO; разметка — Open Graph.
  Cookie-баннер — плагин CookieYes. Аналитика — Yandex.Metrika (два счётчика).
- **Семантические элементы HTML5:** header — 1, nav — 3, main — 0, section — 0, article — 1,
  footer — 1. `<article>` используется по назначению — для самой страницы товара/записи
  (стандартная разметка WordPress: `post-5973.page.type-page.status-publish.hentry`). `<main>`
  и `<section>` не используются — контент собран через div-структуру Divi (`et_pb_*`).
- **Div и семантические классы:** классы образуют смесь трёх источников — служебные классы Divi
  (`et_pb_module`, `et_pb_text`, `et_pb_menu_wrap`, `et-l--header`, `et-l--footer`, `et-boc`),
  классы WooCommerce (`woocommerce-page`, `woocommerce`) и стандартные классы WordPress
  (`post-5973`, `page`, `type-page`, `status-publish`, `hentry`).
- **Адаптивность (media-запросы):** сайт адаптивен на обоих брейкпоинтах (375px и 768px),
  визуальных отличий от десктопной версии почти нет — вёрстка на Divi изначально построена
  как гибкая (flexbox/grid + media-запросы Divi под капотом), без отдельного мобильного
  поддомена (в отличие от 21vek.by).
- **Lighthouse:** Performance — 56, Accessibility — 81, Best Practices — 77, SEO — 92
  (⚠ предупреждение теста: "The page loaded too slowly to finish within the time limit,
  results may be incomplete" — сайт на WordPress+Divi+WooCommerce заметно медленнее
  Next.js-сайтов конкурентов)
  Условия проверки: мобильный интернет / дом / 11:50, 23.09.2026
- **LocalStorage / Cookies:** LocalStorage содержит два отдельных счётчика Яндекс.Метрики
  (id 104006266 и 91849682 — вероятно, один общий на группу компаний "ЧайКоффский", второй
  отдельно под сайт/раздел выпечки), стандартный набор ключей `_ym_*` (uid, fingerprint,
  синхронизация визитов). Также найден `wc_cart_hash_...` — служебный ключ WooCommerce для
  отслеживания состояния корзины на клиенте.
- **Маркетинг и аналитика:** по фильтрам `analytics`, `tagmanager`, `hotjar` — не обнаружено.
  По фильтру `metrika` — подтверждена Яндекс.Метрика (YmEc.min.js, tag.js, tag_phono.js,
  tag_ec.js — включая e-commerce-модуль метрики для отслеживания покупок). По фильтру `pixel` —
  найденные запросы (`104006266?wmode=...`, `91849682?wmode=...`) оказались частью той же
  Яндекс.Метрики (счётчики просмотров), а не отдельным рекламным пикселем.
